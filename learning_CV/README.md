# Learning Computer Vision

These notebooks contain my early Computer Vision and CNN learning work.

- `ANN_on_MNIST.ipynb` — ANN digit classification, accuracy, confusion matrix, and incorrect predictions.
- `CV.ipynb` — DenseNet121 chest X-ray classification and segmentation-data exploration.
- `Segmentation.ipynb` — U-Net/ResNet34 setup, Oxford-IIIT Pet masks, preprocessing, and DataLoaders.

The recorded chest X-ray classification accuracy in `CV.ipynb` is **72.92%**. These are educational implementations that helped build the foundation for the later CACR research project.
